مقاله ۲۵ منبع و هفت شکل دارد و نثر انگلیسی آن روان‌نویسی شده است. آزمایش اصلی شامل ۱۰۰ گروه ورودی و ۸۰۰ پاسخ واقعی روی دو مدل و چهار حالت است؛ ماژول عددیِ جدا نیز ۱۰ گروه و ۸۰ پاسخ دارد. پاسخ‌های خام و محاسبات قابل بررسی‌اند. بررسی موردی به‌صورت مدل‌یار ثبت شده و به نام داوری انسانی معرفی نشده است.

از ریشهٔ ریپو، بررسی مستقل را بدون کلید یا درخواست تازهٔ API اجرا کنید:

```bash
python -m pip install numpy==2.3.5
python research/verify_research.py
```

فایل PDF قبلی با متن و نام‌های چاپ‌شدهٔ آن، صرفاً برای حفظ تاریخچه در مسیر قبلی مانده است. هویت نویسنده در نسخهٔ جاری مطابق تصحیح صریح نویسنده، فقط رضوان‌الله موحد است. برای ارسال به استاد و استناد، از فایل‌های همین صفحه استفاده کنید.
