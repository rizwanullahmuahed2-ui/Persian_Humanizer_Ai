# یافته‌های تحلیل مستقل آزمایش تازهٔ API

بررسی مستقل فایل‌ها موفق بود: ۸۰۰ پاسخ با توقف عادی، ۸۰۰ شناسهٔ متفاوت پاسخ API و ۱۰۰ گروه مستقل سوال تأیید شد. تعداد متن‌های خروجیِ متمایز ۵۷۴ است؛ یکسان‌بودن متن بعضی پاسخ‌ها به معنی استفادهٔ دوباره از پاسخ ذخیره‌شده نیست، زیرا شناسهٔ API هر درخواست متفاوت است.

در مجموع ۱۲۰۰ تلاش علمی ثبت شده است: ۴۰۰ پاسخ موفق مدل GPT-4.1 mini، ۴۰۰ خطای HTTP 404 برای مدل برنامه‌ریزی‌شدهٔ nano و ۴۰۰ پاسخ موفق GPT-4o mini در پلان جداگانهٔ تکمیلی. فایل‌های خطای nano حذف یا با موفقیت جایگزین نشده‌اند. دو اجرای تخنیکی بررسی اتصال، بیرون از نمونهٔ علمی‌اند.

مصرف پاسخ‌های موفق ۲۰۱۲۵۲ توکن ورودی و ۱۱۵۵۶ توکن خروجی، در مجموع ۲۱۲۸۰۸ توکن است. برآورد محافظه‌کارانه با نرخ بدون تخفیف کش، ۰٫۰۶۸۰۵۳۹۰ دالر است؛ این رقم صورتحساب نیست.

این نمره‌ها طبیعی‌بودن یا صحت معنا را ثابت نمی‌کنند. بازنویسی ذخیره‌شدهٔ corpus، مرجع تأییدشده برای حفظ لحن و معنا نیست.

یافتهٔ مهمِ مقایسهٔ جفتی این است که چهار مثال معنایی نسبت به حالت بدون مثال، اشتراک با بازنویسی corpus را افزایش می‌دهد؛ اما کنترول تصادفی نیز تقریباً همان اثر را دارد. تفاوت چهار مثال معنایی با چهار مثال تصادفی در ROUGE-L مرجع، برای GPT-4.1 mini برابر ۰٫۰۰۴۹ با فاصلهٔ bootstrap از ‎−۰٫۰۲۲۱ تا ۰٫۰۳۱۷، و برای GPT-4o mini برابر ۰٫۰۰۹۲ با فاصله از ‎−۰٫۰۲۳۲ تا ۰٫۰۴۲۷ است. بنابراین، این آزمایش برتری روشن انتخاب معنایی بر انتخاب تصادفی را در این معیار نشان نمی‌دهد؛ همچنان دربارهٔ کیفیت انسانی نتیجهٔ قطعی نمی‌دهد.

در هیچ‌کدام از ۱۰۰ ورودی انتخاب‌شده یا خروجی‌های‌شان عدد رقمی وجود ندارد. پس شمار صفر تفاوت عددی، «حفظ صد فیصد عددها» نیست؛ مخرج واجد شرایط صفر و نرخ نامعین است. در مجموعهٔ کامل test، ده گروه دارای عدد رقمی در متن ورودی وجود دارند. بررسی جداگانهٔ همهٔ آن‌ها، اگر اجرا شود، باید به‌عنوان ماژول هدفمند پسینی گزارش شود و با نمونهٔ ۱۰۰موردی مخلوط نشود.

معیارها پیش از بررسی متن پاسخ‌ها ثبت شدند. تغییر مدل nano صرفاً بر مبنای خطای دسترسی ثبت شد و اصلاحیهٔ جداگانه دارد. کد تحلیل از runner و harness چیزی import نمی‌کند؛ هش‌ها، نسخهٔ مدل، تعداد مثال واقعی، انتخاب بازیابی و تصادفی، یکسان‌بودن سوال‌ها و پرامپت‌ها، پاسخ خام، مصرف و شناسه‌های پاسخ را مستقلاً تطبیق می‌دهد. هیچ نمرهٔ انسانی تولید نشده است.
